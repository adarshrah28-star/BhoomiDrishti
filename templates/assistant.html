How this works

Each question is matched against a local knowledge base in model/rules.py. Nothing is sent to an external service, so the assistant works with no internet connection and no API key.

To connect a real language model later, replace the body of answer_question() with your API call and keep this keyword matcher as the offline fallback. The rest of the application only ever calls that one function.
